# Tesseract

> "Cut the noise. Find the bottleneck."
> 剔除噪音，找到关键限制因素。

**Tesseract** 是一个极简的商业分析引擎。它只做一件事：**找到一家公司的「关键限制因素」（生死线），再预测这个限制能否被解决、当前解决到什么程度。**

它不下判决、不给结论，只提供基于数据的**预测**。一切指标都只是辅助，最终都服务于"识别关键限制因素 + 判断其解决前景"。

> 📌 **首发范围：** 市场 = A 股 / 港股；行业 = SaaS / 企业软件；形态 = C 端工具（MVP 免费）。
> 📄 完整产品需求见 [PRD.md](./PRD.md)。

---

## 🧠 核心理念

每个商业模式都有且仅有一个**关键限制因素**。Tesseract 分两步：

1. **推导关键限制因素**（核心）：这个行业的生死线是什么？
2. **预测解决前景**：围绕它找代理数据，预测它能否被解决、进展如何。

宁可少看 99 个指标，也要把那 1 个关键限制因素看透。

---

## 🏗️ 架构

三个极简服务串成一条流水线：

| 服务                 | 中文名               | 职责                                                         |
| -------------------- | -------------------- | ------------------------------------------------------------ |
| `Axiom_RuleBase/`    | 公理库               | 存储各行业**唯一的关键限制因素**及其判断逻辑（SaaS → 客户流失/NDR；消费品 → 流量成本）。 |
| `Data_Sniper/`       | 数据狙击手           | 只为推导/印证关键限制因素采集数据，**第三方免费 API 优先，绝不抓取多余数据**。 |
| `Forecast_Core/`     | 预测推演引擎         | 处理时序数据，**预测**关键限制因素的解决前景，而非给出判决。  |

```
公司名/代码 ──▶ Axiom RuleBase ──▶ Data Sniper ──▶ Forecast Core ──▶ 关键限制因素 + 预测
（A股/港股）  （推导关键限制因素）  （免费API优先）    （预测解决前景）
```

---

## 📖 公理库示例（关键限制因素）

| 行业            | 关键限制因素 | 观察用代理指标                |
| --------------- | ------------ | ----------------------------- |
| SaaS / 企业软件 | 客户流失     | NDR（净收入留存率）           |
| 消费品品牌      | 流量成本     | 营销费用率趋势 + 毛利率稳定性 |
| 高端制造        | 技术内卷     | 核心技术/专利新品营收占比     |

> 规则以 JSON/YAML 维护，便于扩充；复合行业的公司可命中多条关键限制因素，分别推演。

## 🚀 Quick Start

前端 MVP 已实现，见 [`tesseract/`](./tesseract/) 目录：

```bash
cd tesseract
npm install
npm run dev
```

浏览器打开开发地址后，在分析页输入 **金蝶国际** 或 **0268.HK** 即可体验主链路（内置 SaaS 规则与示例 NDR 数据，存于 IndexedDB）。

**在线预览：** https://mouse-lincoin.github.io/Tesseract/（Settings → Pages：**main** 分支 **/ (root)**；Actions 将构建产物提交到 main 根目录）

## ⚠️ 免责声明

Tesseract 提供的是对"关键限制因素能否被解决"的**预测**，**不构成任何投资建议**。预测依赖公开数据与代理指标推算，可能存在偏差，使用者需自行判断并承担风险。
