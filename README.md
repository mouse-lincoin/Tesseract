# Tesseract

> "Cut the noise. Find the bottleneck. Verify the truth."
> 剔除噪音，寻找瓶颈，验证真相。

**Tesseract** 是一个极简主义的商业分析验证引擎。它抛弃了传统大而全的多维财务打分模型，转而基于**第一性原理**运作：它认为每个商业模式都有且仅有一个**「关键限制因素（生死线）」**。Tesseract 的目标是锁定这个限制，并通过数据狙击，反复验证目标公司是否突破了该限制。

> 📌 **首发范围：** 市场 = A 股 / 港股；行业 = SaaS / 企业软件；形态 = C 端工具（MVP 阶段完全免费）。
> 📄 完整产品需求请见 [PRD.md](./PRD.md)。

---

## 🧠 The Core Philosophy（核心哲学）

传统金融工具给你 100 个指标让你迷失。Tesseract 只问三个问题：

1. **The Limit（限制）：** 这个行业的物理极限 / 生死劫是什么？
2. **The Proxy（代理）：** 哪些数据 / 替代指标能证明这个极限？
3. **The Verdict（判决）：** 这家公司突破限制了吗？

> **数据只是辅助。** 一切指标都服务于唯一目标——推导并验证"关键限制因素"是否被突破。最终只给出一个二元结论：`未突破 (Restricted)` 或 `已破壁 (Wall-Broken)`。

## 🏗️ Architecture（极简架构）

系统仅由三个极简服务串联成一条流水线：

| 服务                  | 中文名     | 职责                                                                 |
| --------------------- | ---------- | -------------------------------------------------------------------- |
| `Axiom_RuleBase/`     | 公理库     | 存储不同商业模式的"限制字典"（如 SaaS → NDR 留存；制造业 → 良率/毛利剪刀差）。 |
| `Data_Sniper/`        | 数据狙击手 | 根据公理库下发的任务，优先通过**第三方免费数据 API** 精准抓取目标公司对应的财报片段、披露字段或代理指标。**绝不抓取多余数据。** |
| `Verification_Core/`  | 验证内核   | 处理时序数据，跑出趋势线，判断是否完成"破壁（Wall-Breaking）"；复合行业逐条判决并汇总。 |

```
公司名/代码 ──▶ Axiom RuleBase ──▶ Data Sniper ──▶ Verification Core ──▶ 判决书
（A股/港股）   （该验证什么）      （免费API优先）    （时序+破壁判定）     （一句话+一张图）
```

## 📖 行业公理库示例（The One Rule）

| 行业            | 核心限制（生死线） | 验证指标                        | 破壁阈值（示例）               |
| --------------- | ------------------ | ------------------------------- | ------------------------------ |
| SaaS / 企业软件 | 客户流失           | NDR（净收入留存率）             | NDR > 115%                     |
| 消费品品牌      | 流量反噬           | 营销费用率趋势 + 毛利率稳定性   | 营销费用率持续下降且毛利率企稳 |
| 高端制造        | 技术内卷           | 核心技术/专利新品营收占比       | 占比 > 30%                     |

> 阈值均为可配置项，规则以结构化配置（JSON/YAML）维护，便于持续扩充。
> 一家横跨多业务的公司（如硬件 + SaaS）可命中**多条生死线**，系统将分别判决并汇总。

## 🚀 Quick Start（快速开始）

> ⚠️ **当前状态：** 项目处于概念 / 文档阶段，下述命令为规划中的目标用法，代码尚未实现。

```bash
# 1. 克隆仓库
git clone <repo-url>
cd tesseract

# 2. 安装依赖（技术栈待定，示例以 Python 为例）
pip install -r requirements.txt

# 3. 运行一次"破壁验证"（A 股 / 港股标的）
tesseract verify "金蝶国际"
# 或使用股票代码
tesseract verify 0268.HK
```

预期输出：

```
公司：金蝶国际 (0268.HK)
行业：SaaS / 企业软件
生死线：客户流失（验证指标 NDR > 115%）
近 5 年 NDR 趋势：105% → 109% → 112% → 114% → 113%
─────────────────────────────────────────────
判决：⛔ 未突破 (Restricted)
理由：NDR 持续逼近但尚未稳定站上 115% 阈值，仍未彻底摆脱"客户流失"这一行业生死线。
```

## 📂 Project Structure（规划中的目录结构）

```
tesseract/
├── Axiom_RuleBase/        # 公理库：行业限制规则定义
│   └── rules/             #   各行业规则配置（JSON/YAML）
├── Data_Sniper/           # 数据狙击手：第三方免费 API 接入 + 代理指标推算
├── Verification_Core/     # 验证内核：时序趋势 + 破壁判定 + 多规则汇总
├── ui/                    # 判决书前端（极简深色界面，C 端）
├── PRD.md                 # 产品需求文档
└── README.md
```

## 🛣️ Roadmap（路线图）
